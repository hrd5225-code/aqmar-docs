# مستندات أقمار المداري

1. ارفع كل محتويات هذا المجلد إلى مستودع GitHub (بما فيها المجلد .github).
2. فعّل Settings > Pages (Deploy from a branch: main, root).
3. من تبويب Actions شغّل Download offline libraries (Run workflow) مرة واحدة: يحمّل الخط ومكتبتي PDF داخل مجلد vendor.
4. بعدها يعمل التطبيق بدون إنترنت.

للتحديث لاحقًا: غيّر رقم النسخة في sw.js (docs-v3 إلى docs-v4).
